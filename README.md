# spheroid-drug-response-ai-

Interactive research dossier by Djamel Zair (MSc Artificial Intelligence, University of Amsterdam).

Live page: https://djamelzair.github.io/spheroid-drug-response-ai-/

Deep-learning segmentation of time-lapse microscopy of chronic lymphocytic leukaemia (CLL) patient cell clusters,
shape measurements, and inference of cell-level forces by matching against Cellular Potts (CompuCell3D)
simulations run on the Snellius supercomputer, applied to a 17-drug panel on patient wells.

Static site: plain HTML, CSS and JavaScript with hand-drawn SVG charts; no build step. Every number on the page is
read from the project's result files.

Full analysis and notebooks: https://djamelzair.github.io/EDA_SpheroidAnalysisforCPM_DDZair/
Pipeline code: https://github.com/DjamelZair/CPM-parameter-Posterior-Estimate-Generator
